DM summary

DOP = POS GPA + pickup GPA − 前線 TM、office、disposal、租金、營運、倉庫及物流、capex 同 marketing 成本。100% commission target 同 commission 級別來自「（月份）Target %」tab；Commission now = Target tab 預計 DOP 做到嘅最高級別（低過 50% 級別即 0%）。Projected DOP、達標 % 同差距來自 Target tab（唔計 outlet，用 Target tab 自己嘅日數推算）。

AM summary

Projected DOP = DOP × 當月日數 ÷ 已有 POS 銷售嘅日數，同 Sheet 一樣。DOP ach. % 跟 Target tab 計法：預計 DOP ÷ target；target 係負數時用 target ÷ 預計 DOP。

TM cost vs target

TM cost 全部來自 TM cost sheet「」（已剔除 DM、AM）：TM cost (MTD) = 實數小計（），Projected TM cost = Projection 合計，Target TM cost = 「 TM Cost (excl. DMAM)」，DEF = target − projection（負數 = 超咗 target，紅色）。Target % 來自「O2O Shop Target 2026」sheet 嘅「 TM cost target」：TM cost ÷（POS GPA + Pickup GPA）嘅目標（Pickup GPA = pickup GMV × 6.9%）。GPA 用 DOP sheet「Raw」每日數；預計 GPA = 月初至今 GPA ÷ 已有日數 × 全月日數。DM / AM 合計 % = Σ TM cost ÷ Σ GPA；合計 Target % = Σ Target TM cost ÷ Σ（Target TM cost ÷ 該舖 target %）。跟 Shop tier 篩選。
